# Sociais em igreja

* __OBJETIVO__

Criar um sistema local que ajude os irmãos da igreja a controlar os eventos de sociais

### Problema de negócio

Notei uma certa dificuldade na gestão de dinheiro 
durante algumas sociais na igreja (sociais são eventos que envolve venda de produtos como pasteis, minipizza, espetinho e outros).

Como nessas sociais o fluxo de irmãos (clientes) era muito grande a confusão gerou gargalos/problemas:
1. Entrega dos bilhetes para retirada dos produtos
2. Falta de organização na ordem da fila
3. Falta de prioridade de quem reservou o produto e pagou com antecedência
4. Incerteza no faturamento e nos gastos
